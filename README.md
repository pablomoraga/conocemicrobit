# Conoce micro:bit

Recurso educativo (eXeLearning) para conocer la placa **micro:bit v2** y aprender a programarla con **MakeCode** mediante misiones.

[![Abrir el recurso](https://img.shields.io/badge/▶_Abrir_el_recurso-2ea44f?style=for-the-badge)](https://pablomoraga.github.io/conocemicrobit/)

## Contenido
- Conoce micro:bit v2 y Explora micro:bit
- Misiones con MakeCode:
  1. Misión Cero
  2. Alarma Solar
  3. ¡Silencio, se estudia!
  4. Bola de Cristal
  5. Bomba:BIT
  6. Orientación
  7. Equipo de radio
- Propuesta de proyecto: Casa Inteligente
- Para ampliar
